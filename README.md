# FlowForge Pro

FlowForge Pro is a modern, offline‑ready task and project manager built with plain JavaScript, HTML and CSS.  It runs entirely in the browser and stores your tasks locally, so you can use it without an internet connection once it's loaded.

## Features

* **Tasks and Categories** – Create tasks with titles, descriptions, due dates and priority.  Organise tasks into categories.
* **Filtering and Sorting** – Filter by category, search by keyword, and sort by due date, priority or creation date.
* **Dark/Light Theme** – Toggle between light and dark modes.  The choice is remembered across sessions.
* **Offline Support** – A Service Worker caches core assets, allowing you to manage tasks when offline.
* **Progressive Web App** – Includes a web app manifest and icons so you can install FlowForge Pro on your device.

## Setup

To run FlowForge Pro locally, simply open `index.html` in a modern browser.  You can also deploy the app to GitHub Pages or any static hosting provider by serving the files in the repository root.

### GitHub Pages Deployment

If you want to host FlowForge Pro on GitHub Pages:

1. Create a new GitHub repository and upload all files in the `flowforge-pro` folder.
2. Commit and push to the `main` branch.
3. Navigate to **Settings → Pages** in your repository.
4. Select `main` branch and the **root** folder ("/**").  Save.
5. After a few minutes, your site will be available at `https://<yourusername>.github.io/<repository>/`.
